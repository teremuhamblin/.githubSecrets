# 📁 Les secrets 
- Du dossier `.github/`
- Projet `.githubSecrets`

### 📁 Mise a jour `.github/`
- Le dossier `.github/` est un dossier **magique** que GitHub lit automatiquement.
### 🔧 1. Templates d’issues
GitHub les utilise pour pré-remplir les formulaires.
### 🔀 2. Templates de PR
Permet d’imposer un format aux contributeurs.
### ⚙️ 3. Workflows GitHub Actions
Automatisation : CI, tests, déploiement, lint, releases.
### 👑 4. CODEOWNERS
Définit qui doit valider les PR.
### 🛡 5. SECURITY.md
GitHub le lit pour afficher la politique de sécurité.
### 💰 6. FUNDING.yml
Affiche le bouton “Sponsor”.
### 🧪 7. dependabot.yml
Surveille les dépendances automatiquement.
### 🎯 Conclusion
Le dossier `.github/` est le **centre nerveux** d’un projet GitHub professionnel.

- Le dossier `.github/` est un espace spécial que GitHub lit automatiquement pour configurer :
```text
- les formulaires d’issues
- les templates de PR
- les workflows CI/CD
- les règles de validation via CODEOWNERS
- les politiques de sécurité
- les boutons de financement
- la surveillance des dépendances
```

Ce dépôt `.githubSecrets` montre comment tout cela fonctionne, avec des exemples concrets.
